# Nguyễn Minh Nhật — Cyberpunk DevOps Portfolio

Mẫu portfolio một trang mang phong cách cyberpunk, được xây dựng bằng HTML, CSS và
JavaScript thuần.

## Chạy local

```bash
python3 -m http.server 4173
```

Sau đó mở `http://localhost:4173`.

## Tùy biến nhanh

- Nội dung và thông tin dự án: `index.html`
- Màu sắc, font và layout: các biến trong `:root` của `styles.css`
- Menu, hiệu ứng reveal và bộ lọc dự án: `script.js`

Mẫu có responsive layout, mobile navigation, keyboard focus, reduced-motion và
bộ lọc dự án theo danh mục.
